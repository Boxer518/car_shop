# Автосалон

Веб-клиент салона на Flutter. Данные и вход живут в PocketBase: схема, роли и правила доступа описаны в `pocketbase/pb_migrations`, расчёт цены и занятость тест-драйва — в `pocketbase/pb_hooks`.

Восемь сущностей:

| Сущность | Связи |
| --- | --- |
| Марка | один ко многим с моделями |
| Модель | многие к одному с маркой, один ко многим с автомобилями |
| Опция | многие ко многим с автомобилями |
| Автомобиль | многие к одному с моделью |
| ПТС | один к одному с автомобилем |
| Клиент | один к одному с учётной записью покупателя |
| Сделка | многие к одному с автомобилем, клиентом и менеджером |
| Тест-драйв | многие к одному с автомобилем и клиентом |

## Роли

У каждой роли есть раздел, которого нет у остальных.

- Покупатель: «Мои записи». Каталог только для чтения.
- Менеджер: «Сделки» и «Тест-драйвы».
- Директор: «Отчёт» и «Сотрудники».

Чужой адрес открывает экран «Недостаточно прав». Кнопки чужой роли не показываются.

Готовые входы:

| Email | Пароль | Роль |
| --- | --- | --- |
| director@salon.local | director123 | директор |
| manager@salon.local | manager123 | менеджер |
| buyer@salon.local | buyer123 | покупатель |

Панель PocketBase: `admin@salon.local` / `admin12345`.

## Запуск

Из папки `pocketbase`:

```powershell
.\pocketbase.exe serve --http=127.0.0.1:8090
```

Панель: http://127.0.0.1:8090/_/  
API: http://127.0.0.1:8090/api/

Из корня проекта, вторым окном:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://127.0.0.1:8090
```

`API_BASE_URL` по умолчанию уже `http://127.0.0.1:8090`. Пустой `--dart-define=API_BASE_URL=` перебивает это значение, поэтому в сборке его добавляют только когда адрес задан.

База лежит в `pocketbase/pb_data` и в git не входит. Первый запуск применяет миграцию и заполняет каталог. Чтобы начать с чистой базы, остановите сервер и удалите `pb_data`.

## Что умеет клиент

Списки ищут, фильтруют минимум по трём полям, сортируют и листают страницами на сервере. Выбранные условия записаны в адресе, ссылку можно открыть ещё раз. Сессия хранится в браузере и переживает перезагрузку.

У каждой сущности есть создание, просмотр, правка и удаление. Удаление бывает логическим (запись можно вернуть, в том числе пачкой) и физическим. Физическое удаление доступно директору и не проходит, если на запись ещё ссылаются другие.

Ошибки полей показываются у самих полей. Коды 400 и 422 разбираются в ошибки формы, 409 — в конфликт (занятый интервал, уже проданный автомобиль, чужая цена, связь при удалении). Обрыв связи и таймаут показывают отдельное сообщение. Просроченный токен один раз обновляется через `auth-refresh`; если обновить нельзя, сессия закрывается.

Ширина 360–767: нижнее меню, лишние разделы в «Ещё», одна колонка карточек. 768–1279: боковое меню со значками и две колонки. От 1280: подписи в меню и таблица. От 1920 содержимое уже 1200 пикселей по центру.

## Правила салона

Скидка считается на сервере и тем же правилом в клиенте:

- пробег от 100 000 км — 5%;
- возраст от 5 лет — ещё 3%;
- менеджер добавляет свою скидку до 15%, директор — до 25%;
- итог округляется до рубля.

Если присланная цена расходится больше чем на рубль, сервер отвечает 409. После сделки автомобиль становится проданным.

Тест-драйв длится от 30 минут до 3 часов. Второй живой интервал на ту же машину отвечает 409. Отменённая и скрытая запись интервал не занимает.

Отчёт директора показывает остатки, сумму сделок и полосы продаж по маркам.

## Сборка и публикация

Релизная сборка без wasm:

```powershell
flutter build web --release --base-href /ИМЯ_РЕПОЗИТОРИЯ/
copy build\web\index.html build\web\404.html
```

`404.html` нужен, чтобы GitHub Pages отдал приложение по прямой ссылке на внутренний экран, а не свою страницу 404. `<base href>` в `web/index.html` подставляет этот префикс.

Измеренный JS-бандл этой сборки: `main.dart.js` 2 953 072 байта, gzip 873 106. Движок CanvasKit — `canvaskit/canvaskit.wasm` 7 315 452 байта.

Workflow `.github/workflows/web.yml` гоняет тесты, анализатор и формат, собирает веб с `--base-href /имя-репозитория/`, копирует `404.html` и выкладывает GitHub Pages. Адрес API берётся из переменной репозитория `API_BASE_URL` и попадает в сборку только если она не пустая.

Страницы GitHub открываются по HTTPS и не вызывают PocketBase по `http://127.0.0.1`. Для публичной ссылки нужен PocketBase с HTTPS. Локально клиент и сервер работают по адресам выше.
